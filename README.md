# Institutional Asset Management System
A web-based Institutional Asset Management System developed as my
BCA final-year project.

## Overview
The system is designed to manage institutional assets and related
requests through a centralized web application.

## Features
- Asset registration and inventory management
- Asset quantity and status tracking
- Teacher/user management
- Department management
- Classroom and laboratory management
- Office and public-area management
- Asset requests
- Special requests
- Complaint management
- Request approval/status tracking
- Dashboard with inventory statistics
- User authentication

## Technology Stack
- PHP
- JavaScript
- MySQL
- HTML
- CSS
- WAMP

## Project Structure
The application consists of PHP-based modules connected to a
MySQL database, with JavaScript and CSS used for client-side
interaction and interface design.

## Running Locally
1. Install WAMP.
2. Place the project inside the WAMP `www` directory.
3. Start Apache and MySQL.
4. Create the required MySQL database.
5. Import the SQL database file.
6. Configure the database connection if required.
7. Open the application through `localhost`.
